方式 1 · Network 面板（推荐）
① 在 Yahoo 页面按 F12 → 点顶部 Network
② 在请求列表上方的筛选框里输入 fantasy 并回车
③ 按 ⌘+R 刷新，列表会只剩 Yahoo 的请求
④ 点列表中任意一条（名字不重要）
⑤ 右键那条 → Copy → Copy as cURL
⑥ 回到这里 ⌘+V 粘贴，点下面的「测试」

💡 如果列表是空的：把筛选框清空，按 ⌘+R 重刷；或者把 Network 上方的 All 选中（不要选 Fetch/XHR）。

方式 2 · Application 面板（能看到 HttpOnly 的 Cookie）
① F12 → 点顶部 Application（应用）
② 左侧 Storage → Cookies → https://basketball.fantasysports.yahoo.com
③ 表格里能看到 A1 / A3 / A1S 等
④ 逐个双击 Value 单元格复制，按 名字=值; 名字=值 拼起来
（麻烦，但一定能拿到）

方式 3 · 直接读控制台
F12 → Console → 输入 document.cookie → 回车
⚠️ 如果输出里没有 A1=，这个方法拿不到完整 Cookie，请用方式 1。
